7. 统计与不确定度符号（"这个数能信多少"）

符号值来源作用 / 含义注意
δκ/κ1.9–5.0%拟合导出κ 的条件重复性标准误不含系统误差
δν/ν24–78%拟合导出ν 的条件重复性标准误被"近等量相减"放大

逐周期 κ 范围6.40–7.14×10⁻⁵（10.9%）拟合导出同一窗口内五个周期的散布漂移所致，不是置信区间
三层不确定度的说法（背下来）：
① 条件重复性：κ 2–5%、ν 24–78%（同一段数据内）；
② 跨频段离散：κ 0.8%、span 4.9%（不同频率之间）；
③ 系统误差：位置、偏置、漂移、端部 —— 主导项，但没有标准不确定度，只能给区间。
所以 k = 165 ± 5 W/(m·K) 是"统计 2–5% ⊕ 材料 1.5%"的结果，而 h 只能报"9–18"。

10.2 一阶敏感性（"这个常数变 1%，结果变多少"）

k = κ · ρ · c δk/k = δκ/κ ⊕ δρ/ρ ⊕ δc/c → ρ 变 1% ⇒ k 变 1% ; c 变 1% ⇒ k 变 1% ; κ 变 1% ⇒ k 变 1% h = ν · ρ · c · d/4 δh/h = δν/ν ⊕ δρ/ρ ⊕ δc/c ⊕ δd/d → ν 变 1% ⇒ h 变 1%（但 ν 自身误差 24–78%） → d 变 1% ⇒ h 变 1% ; ρc 变 1% ⇒ h 变 1%

读法：公式看上去"四个都对 h 有贡献"，但量级差两个数量级 —— ν 的 24–78% 压倒 ρ、c、d 的 1–2%。所以"改进 h"只有两条路：降低放大因子（更长周期）、压低 δq′（更稳窗口/更准相位）。

一句话总结整张表：整条链上真正"借来"且会进结果的只有 ρ 与 c（合计 ~1.5%）；d、L、x 是实测几何（x 最要命）；h = 10、k = 166–172 只是预测与对照；ratio、Kp、Ki、pwm_limit 决定"边界交得干不干净"；mL、εT、Bi⊥ 只是"能不能这样用"的判据。
