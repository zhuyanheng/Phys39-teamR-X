§0.1 开场总述（45 秒，所有问题的落脚点，务必背熟）
The TEC imposes a sinusoidal temperature at the rod base. As the oscillation travels, diffusion makes it decay and lag, and side loss drains it. Fitting each sensor gives an amplitude and a phase; their slopes versus position are q and q-prime. Because the equation is linear, one complex exponential carries both: the imaginary part gives kappa = omega over 2 q q-prime, the real part gives nu = kappa times (q squared minus q-prime squared). Multiplying by rho c gives the aluminium conductivity k; multiplying by rho c A over P gives the side-loss coefficient h. Five forcing periods give kappa to 0.8 per cent, k one to four per cent below the 6061-T6 handbook range, and h only to a factor of two, because nu is a near-cancellation.

Q1How are q and q′ obtained from the measured amplitudes and phases? 官方 1/9 · 图 6-1
30 秒版：对每个传感器在选定窗口内做固定频率的正弦拟合，得振幅 Bᵢ 与相位 φᵢ；再把 ln Bᵢ 对 x 做直线拟合、斜率 = −q；把展开后的 φᵢ 对 x 拟合、斜率 = −q′。

完整过程

① 模型。 线段方程的稳态周期解在同一频率下是

T_i(t) = a_i + B_i cos(ωt + φ_i)

ω = 2π/T 由固件设定（100–500 s ⇒ 0.01257–0.06283 rad/s），不作为拟合参数；若拟合出的频率偏离设定值超过 1/T，说明有频率误差或漂移。

② 线性化技巧（关键）。 把相位展开：

B cos(ωt + φ) = C cos(ωt) + S sin(ωt), C = B cos φ, S = −B sin φ

于是模型对 (C, S) 是线性的，可用闭式最小二乘，不必做非线性迭代：

X = [1, cos ωt, sin ωt] (N × 3) coef = (XᵀX)⁻¹ Xᵀ y → (a, C, S) B = √(C² + S²) φ = atan2(−S, C)

③ 误差传递。 由 cov = (XᵀX)⁻¹·σ²（σ² = SSR/(N−3)）与雅可比：

δB = √[ (C/B)² var(C) + (S/B)² var(S) + 2(CS/B²) cov(C,S) ] δφ = √[ (S/B²)² var(C) + (C/B²)² var(S) − 2(CS/B⁴) cov(C,S) ]

这就是 CSV 里 amplitude_se_C、phase_se_rad 的来源（200 s：δB ≈ 2×10⁻⁴ °C、δφ ≈ 4×10⁻⁵ rad —— 单点拟合极准，真正的误差在下面两步）。

④ 空间拟合（两阶段法）。 模型给出两条直线：

B(x) = B₀ e^{−q x} ⇒ ln B_i = ln B₀ − q x_i φ(x) = φ₀ − q′ x ⇒ φ_i = φ₀ − q′ x_i q = −d(ln B)/dx [1/m] q′ = −dφ/dx [1/m] （相位已展开）

⑤ 只用三个传感器。 保留判据是振幅信噪比 > 5。100 s 时 B(T5)/B(T1) = e^{−21.26×0.1915} = 1.7%，绝对振幅只有 0.020 °C，已进噪声；T1–T3 的 SNR 合格，所以进入拟合。

Q2Why are both amplitude decay and phase lag needed to separate diffusivity from side heat loss? 官方 2/9 · 图 7-3
30 秒版：未知数有两个（κ、ν），而稳态只给一个组合量 m² = ν/κ。一次正弦采集给出两个独立的数（q 与 q′），对应两条独立方程；少任何一个都欠定。

完整论证（三层）

第一层：数方程。

观测个数能写出的方程可解性
稳态剖面1m² = hP/(kA) = ν/κ2 未知数、1 方程 → ❌
只有振幅1q² = (m²/2)(√(1+Ω²)+1)仍含 κ 与 ν → ❌
只有相位1q′² = (m²/2)(√(1+Ω²)−1)仍含 κ 与 ν → ❌
振幅 + 相位2ω = 2κqq′；ν = κ(q²−q′²)✅ 两个方程两个未知数

第二层：为什么单看一个不行（显式）。 令 Ω = ω/ν、m² = ν/κ，则

q² = (m²/2)·( √(1+Ω²) + 1 ) ← 同时依赖 m（=ν/κ）与 Ω（=ν） q′² = (m²/2)·( √(1+Ω²) − 1 ) ← 同样同时依赖两者

也就是说：衰减里混着漏热——漏热越大，同一频率下衰减越快，看起来"像扩散慢"。只有把 差 q² − q′² 拿出来，漏热项才被消掉，只剩 m² = ν/κ；而 积 2qq′ 单独给出 ω/κ。

第三层：物理图像。

  • 相位滞后 = 扩散的指纹：热量要"走"过去才有滞后，纯扩散时滞后 ∝ √ω；
  • 额外衰减 = 漏热的指纹：热量边走边被空气拿走；
  • 稳态时两者合成一个指数 e^{−mx}，分不开。

若 ν = 0（侧壁绝热）会怎样？ 此时 q = q′ = √(ω/2κ)，两者被锁死成一个数 —— 永远得不到第二个观测。

Q3Derive or explain κ = ω/(2qq′) and ν = κ(q² − q′²), including units. 官方 3/9 · 核心推导
30 秒版：把 θ ∝ e^{iωt}·e^{−(q+iq′)x} 代入 ∂θ/∂t = κ∂²θ/∂x² − νθ：左端得 iω，右端得 κ(q²−q′²+2iqq′)−ν。虚部给 ω = 2κqq′，实部给 ν = κ(q²−q′²)。

完整推导（九步）

(1) 出发点。

θ(x,t) = T(x,t) − T∞ ∂θ/∂t = κ ∂²θ/∂x² − νθ κ = k/(ρc) [m²/s] ν = hP/(ρcA) [1/s]

(2) 试探解（线性、常系数 ⇒ 单频驱动产生同频响应，只改幅值与相位）。

θ = Re[ Θ₀ · e^{iωt} · e^{−sx} ], s = q + i q′ （复数波数）

(3) 求导。

∂θ/∂t = iω · θ ∂²θ/∂x² = s² θ = (q + iq′)² θ = (q² − q′²) θ + i(2qq′) θ

(4) 代入并两边除以 θ。

iω = κ[ (q² − q′²) + i(2qq′) ] − ν

(5) 分成实部 / 虚部（全题的关键一步）。

实部： 0 = κ(q² − q′²) − ν ⇒ ν = κ (q² − q′²) 虚部： ω = 2κ q q′ ⇒ κ = ω / (2 q q′)

(6) 两式相除，得到"桥"。

ν/κ = q² − q′² = m²

(7) 逆解（实验用的形式）。

κ = ω / (2 q q′) ν = κ (q² − q′²) = ω(q² − q′²) / (2 q q′)

(8) 量纲检查。

q² = (m²/2)·( √(1+Ω²) + 1 ) q′² = (m²/2)·( √(1+Ω²) − 1 ) q² − q′² = m² （恒等式，与 Ω 无关） 2qq′ = m²Ω = ω/κ

Q4How are κ and ν converted into aluminium conductivity k and side heat-transfer coefficient h? 官方 4/9 · 图 7-2
30 秒版：把定义倒过来：k = κρc；h = νρcA/P = νρc(d/4)。前者把"温度扩散快慢"换成"导热能力"，后者把"体积散热率"换成"单位面积对流系数"。

完整过程

(1) 两个定义（都来自主方程除以 ρcA）。

κ = k/(ρc) ← 扩散项系数 ν = hP/(ρcA) ← 侧向项系数（P/A 来自"表面积 / 体积"）

(2) 逆解。

k = κ · ρ · c h = ν · ρc · A/P = ν ρ c (d/4) ∵ A/P = (πd²/4)/(πd) = d/4

(3) 数字代入。

ρc = 2700 × 896 = 2.4192×10⁶ J/(m³·K) k = 6.798×10⁻⁵ × 2.4192×10⁶ = 164.5 W/(m·K) d/4 = 0.01277/4 = 3.1925×10⁻³ m h = ν × 2.4192×10⁶ × 3.1925×10⁻³ = ν × 7.723×10³ 200 s: ν = 1.212×10⁻³ → h = 9.36 W/(m²·K)

(4) 单位验证。

[κρc] = (m²/s)(kg/m³)(J/(kg·K)) = J/(s·m·K) = W/(m·K) ✅ [νρc(d/4)] = (1/s)(J/(m³·K))(m) = J/(s·m²·K) = W/(m²·K) ✅

(5) 物理含义。 k 是材料"导走热量"的能力（1 K/m 的梯度能推多少 W/m²）；h 是表面"向空气交货"的能力（每 m²、每 K 温差带走多少 W）。两者靠 ρc 与 A/P 联系，但测法完全不同：κ 来自时间与空间，k 靠材料常数换算。

Q6Which systematic uncertainty most limits your reported k or h, and why? 官方 6/9 · 图 7-3
30 秒版：k 受限于 q、q′ 的斜率（传感器位置、通道偏置、窗口漂移），量级几个百分点；h 受限于"近等量相减"：q² − q′² 是两个几乎相等的数之差，条件数 6–26，加上漂移与没有独立室温。所以 k 能报 ±5%，h 只能报一个倍数。

① 误差传播（解析）

κ = ω/(2qq′) ⇒ δκ/κ = √[ (δω/ω)² + (δq/q)² + (δq′/q′)² ] k = κρc ⇒ δk/k = δκ/κ ⊕ δρ/ρ ⊕ δc/c ν = κ(q² − q′²) ⇒ δν/ν = √[ (δκ/κ)² + (2qδq ⊕ 2q′δq′)² / (q²−q′²)² ] h = νρc(d/4) ⇒ δh/h = δν/ν ⊕ δρ/ρ ⊕ δc/c ⊕ δd/d

关键在第三式：分母 q²−q′² 很小，分子含 q²、q′² 的误差，于是有放大因子

Q9What phase convention did you use? Why must the phases be unwrapped before fitting the spatial phase coefficient q′? 官方 9/9 · 图 6-2
30 秒版：约定 T = a + B cos(ωt + φ)，等价 φ = atan2(−S, C)；在此约定下下游滞后表现为 φ 更小，所以 φ–x 斜率是 −q′。atan2 只返回 (−π, π]，而相位在 19 cm 上累计可达 4.2 rad，超过 π 就会跳变，不展开则斜率整体错 2π/Δx。

完整说明

(1) 约定的两种写法与等价性。

形式 A：T = a + B cos(ωt + φ) ⇒ C = B cos φ, S = −B sin φ ⇒ φ = atan2(−S, C) 形式 B：T = a + C cos ωt + S sin ωt （同一件事）

若改成 cos(ωt − φ)，则 φ 与 q′ 同时反号；物理不变，但报告必须声明。

(2) 为什么这个约定下斜率是 −q′。

φ(x) = φ₀ − q′ x （下游更晚 ⇒ φ 更小 ⇒ q′ > 0） slope = −q′

(3) 为什么必须 unwrap（定量）。

atan2 的输出 ∈ (−π, π] 19.15 cm 上的累计相位差： 100 s: q′ × 0.1915 = 21.89 × 0.1915 = 4.19 rad (> π) 200 s: 15.06 × 0.1915 = 2.88 rad 500 s: 8.85 × 0.1915 = 1.69 rad 每 5.1 cm 间隔：100 s 时 1.12 rad

(4) 正确做法。

φ_unwrapped = unwrap(φ_raw) # 每步 ±2π 修正 q′ = −slope(φ_unwrapped vs x)

并且要用几何与其它频段交叉验证分支选择：q′ 应随周期单调减（21.9 → 8.9），若某个频段突然反号或跳 2π/Δx，就是解缠错误。

追问：① 约定反过来会怎样？ q′ 变号，κ 里 qq′ 也变号 → κ 会变负；所以符号约定必须与公式一致。 ② 为什么相位比振幅"贵"？ 相位对通道增益不敏感（增益只改 B，不改峰位），是独立信息；但也因此对时间基准与扫描偏斜敏感（0.17 s → 2.9 mrad，已量化）。 ③ 如果相位噪声大怎么办？ 加长窗口（多周期）、降低漂移、修正扫描时序。
陷阱：① 用 atan2(S, C)（漏负号）→ q′ 反号；② 只展开到 ±π 就停（要展开到连续）；③ 忘记在报告里写约定，导致别人无法比较。

30 秒版：m² = hP/(kA) = ν/κ，单位 1/m。1/m 是平均温度衰减长度（你的 17–22 cm）；mL 是"棒长相当于几个衰减长度"（1.24–1.62 ⇒ 端部不"热远"，Θ_tip ≈ 0.44）。它不是独立测量量，而是 ν/κ 的平方根。

m² = hP/(kA) = ν/κ = q² − q′² [1/m²] m = √(hP/(kA)) [1/m] 1/m = 平均场衰减长度 [m]

(2) 它出现在哪两个地方

追问：① m 是波数吗？ 不是。m 是平均场（零频）的衰减常数；振荡的波数是复数 q+iq′。 ② 为什么不能只用 m 求 k？ m 只给 ν/κ 的比值（Q2、Q10）。 ③ m 随频率变吗？ 严格说 h 随温度/位置变，所以不同振幅下 m 会略变；你的 35±5 °C 小振幅把它压到次要。
